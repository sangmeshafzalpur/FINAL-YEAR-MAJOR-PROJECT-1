# Model Architecture: ChilliFusionNet

ChilliFusionNet employs a sophisticated hybrid deep learning architecture designed specifically to balance computational efficiency with the capability to extract highly complex, discriminative features from biological images. The architecture represents a fusion of state-of-the-art convolutional, attention-based, and recurrent methodologies.

## 1. EfficientNetB4 Backbone
The foundation of the model is the `EfficientNetB4` convolutional neural network. 
- **Function**: It acts as the primary feature extractor.
- **Why EfficientNet?**: EfficientNet uniformly scales network width, depth, and resolution using a compound coefficient. This allows it to extract highly robust, hierarchical spatial features from the raw 380x380x3 chilli leaf images with significantly fewer parameters than older architectures like ResNet or VGG.

## 2. Convolutional Block Attention Module (CBAM)
Directly following the backbone, the model integrates a `CBAM` layer.
- **Function**: CBAM is a lightweight, general-purpose attention module that refines the feature maps generated by the EfficientNet backbone.
- **Channel Attention**: It first applies channel-wise attention, determining *"what"* is meaningful in the given input by exploiting the inter-channel relationship of features.
- **Spatial Attention**: It subsequently applies spatial attention, determining *"where"* the informative parts are, highlighting critical disease markers (like lesions or spots) on the leaf.

## 3. Spatial-to-Sequence Transformation
The refined, multi-dimensional feature map outputted by the CBAM module undergoes a reshaping operation. This flattens the spatial dimensions into a sequence of feature vectors, preparing the spatial data to be processed as sequential data.

## 4. Bidirectional Long Short-Term Memory (BiLSTM)
The reshaped sequence is passed into a `BiLSTM` layer.
- **Function**: Standard LSTMs are designed for sequential time-series data. In this spatial context, the BiLSTM processes the sequence of features in both forward and backward directions.
- **Purpose**: This allows the network to capture complex, long-range spatial dependencies and structural relationships across the leaf image that a standard CNN might miss.

## 5. Classification Head
- **Batch Normalization**: Stabilizes the learning process, reduces internal covariate shift, and accelerates convergence.
- **Dropout**: A regularization technique (setting a fraction of input units to 0 during training) that prevents the model from overfitting to the training data.
- **Softmax**: The final dense layer utilizes a softmax activation function to convert the raw logits into a normalized probability distribution across the 5 target classes.
