Component Details

EfficientNetB4

Acts as the primary feature extractor. EfficientNetB4 scales depth, width, and resolution efficiently, extracting robust, hierarchical spatial features from the raw input images.

CBAM

Convolutional Block Attention Module refines feature maps generated by the backbone, applying attention sequentially along channel and spatial dimensions.

Channel Attention

Exploits the inter-channel relationship of features, focusing on "what" is meaningful in the given input by aggregating spatial information using average and max pooling.

Spatial Attention

Focuses on "where" the informative parts are located. It highlights critical disease markers on the leaf by generating a spatial attention map.

BiLSTM

Bidirectional Long Short-Term Memory processes feature sequences in both forward and backward directions, capturing complex, long-range spatial dependencies within the leaf structure.

Classification Head

Projects the refined feature representation into the target class space using a fully connected dense layer, preparing the activations for final softmax probability distribution.
